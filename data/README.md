# Dataset

This project uses the BigIdeasLab STEP Heart Rate Smartwatch Dataset available through PhysioNet.

The dataset contains synchronized wearable PPG recordings and ECG reference signals collected from multiple commercial wearable devices.

Due to dataset distribution restrictions and privacy considerations, raw signal files are not included in this repository.

## Dataset Source

PhysioNet:
BigIdeasLab STEP Heart Rate Smartwatch Dataset

## Devices

The dataset includes recordings from:

- Apple Watch
- Fitbit
- Garmin
- Xiaomi Mi Band
- Empatica E4
- Biovotion Everion

Users should download the dataset from the official source and update the data paths before running the pipeline.
